# 像素坦克大战（XBuilder · 1024 Hackathon）

经典坦克大战的现代重制：一发致命、子弹反弹、每 15 秒刷新随机装备，支持 1v1 / 4 人混战 / 8 人混战，以及经典与人机无限刷新的肉鸽模式。纯前端 Canvas 实现，零依赖。

## 运行

需要先起一个本地静态服务器（ES module 不能直接从 `file://` 打开）。

```bash
# 方式一：无需安装任何依赖（需要 Node 18+）
npm start
# 打开 http://localhost:8000

# 方式二：用 Python
python -m http.server 8000
# 打开 http://localhost:8000
```

自定义端口：`PORT=8080 npm start`。

## 操作

| 按键 | 作用 |
| --- | --- |
| W A S D / 方向键 | 八方向移动（坦克朝向即射击方向，可斜向开火） |
| J / 空格 | 开火（按住连射） |
| Esc | 暂停 / 继续 |

## 玩法

- 一发命中即淘汰；无装备时射击间隔 1 秒，子弹可反弹 4 次。
- **经典模式**：清光所有人机即胜利；**肉鸽模式**：人机每 15 秒一次性补满至「人数 - 1」，刷新位置随机且远离玩家，无尽生存并累计击杀。
- 地图为经典迷宫砖墙，尺寸随人数放大：1v1 = 2×2、4 人 = 4×4、8 人 = 6×6（基准地图的宽高倍数），镜头跟随并带小地图；装备位置在小地图上用彩色闪烁点标出，出屏时画面边缘有同色箭头指向。
- 每 15 秒在随机位置刷新一件装备，场上不限数量，30 秒未拾取则消失；人机同样会拾取并使用装备。

### 装备

| 装备 | 效果 |
| --- | --- |
| 激光 | 3 次；瞬时光线，最多反弹 4 次，第 5 次碰到墙停止 |
| 穿透激光 | 1 次；蓄力 1 秒，宽度等于车身，距离无限，贯穿并破坏墙体，不反弹 |
| 霰弹 | 5 次；一次 3 发并行弹丸，每发可反弹 6 次 |
| 快速射击 | 10 秒；射击间隔 0.3 秒，子弹反弹 4 次 |
| 无敌 | 10 秒；免疫一切攻击，但仍会被墙体和其他坦克阻挡 |
| 反甲 | 10 秒；免疫该次伤害并把攻击者淘汰（伤害返还给攻击者） |

## 结构

```
index.html        界面骨架（菜单 / HUD / 结算）
styles.css        像素风格样式
server.mjs        零依赖静态服务器
src/config.js     常量、装备表、人数与地图倍率
src/map.js        迷宫生成、碰撞查询、出生点与连通性
src/entities.js   坦克 / 子弹 / 装备实体
src/weapons.js    开火逻辑、激光反弹、穿透光束、装备生效
src/ai.js         人机寻路、瞄准与开火
src/render.js     Canvas 绘制与小地图
src/main.js       游戏循环、输入、状态机、HUD
tests/smoke.mjs   逻辑冒烟测试（迷宫连通、激光反弹、穿透、装备计时）
```

## 说明

- 八方向移动与斜向开火：转弯按轴分解，贴墙时会沿墙滑动；子弹与激光按墙面的法线方向反弹（斜射时反弹为镜面反射）。
- 霰弹采用「三发平行弹丸」而非扇形散射：本作的反弹按四方向法线计算，平行三发与碰撞模型一致。
- 人机同样会拾取装备并使用对应武器。
- 基础地图为 8×7 格，按人数放大后 1v1 为 16×14 格（512×448 像素）。
