# 像素坦克大战（XBuilder · 1024 Hackathon）

经典坦克大战的现代重制：一发致命、子弹反弹、每 15 秒刷新随机装备，支持 1v1 / 4 人混战 / 8 人混战，以及经典与人机无限刷新的肉鸽模式。纯前端 Canvas 实现，零依赖。

仓库同时包含 XBuilder（SPX）版本，源码在 `spx/`，由 `tools/gen-spx.mjs` 生成并打包为 `.xbp` 导入 XBuilder。架构与模块规格见 [docs/architecture.md](docs/architecture.md)。

## XBuilder 版

1. 运行 `node tools/gen-spx.mjs` 生成 `spx/`，再用仓库脚本打 zip 包得到 `.xbp`（或直接使用已打好的 `.xbp`）。
2. 在 XBuilder 中选择导入 `.xbp`，项目名与仓库同名。
3. 菜单按键：`1/2/3` 选坦克类型，`C` 切经典/肉鸽，`X` 切 1v1/4人/8人，`空格` 开始；对局中 `WASD`/方向键移动，`J`/`空格` 开火。
4. 彩蛋：在菜单输入 `↑↑↓↓←→←→ B A B A` 切换无敌模式。
5. XBuilder 版地图固定为 4 人尺寸（40×30 格，480×360），背景用舞台 backdrop，保证贴图与碰撞一致。

## 运行

环境：Node 18+（推荐）或 Python 3。必须用本地 HTTP 服务打开——直接双击 `index.html` 会因 ES module 的 CORS 限制停在空白页。

1. 获取代码并进入项目根目录（该目录下能看到 `index.html` 与 `package.json`）：

```bash
git clone https://github.com/CherryPun/xbuilder-tank-battle.git
cd xbuilder-tank-battle
```

2. 启动静态服务器（二选一，都在第 1 步的目录里执行）：

```bash
npm start          # 等价于 node server.mjs，无需 npm install
```

```bash
py -3 -m http.server 8000        # Windows 用 py -3；python 在 PATH 时可用 python -m http.server 8000
```

3. 终端打印 `tank battle running: http://localhost:8000` 后，浏览器打开 http://localhost:8000 ，看到「PIXEL TANK」菜单即启动成功（没看到就 Ctrl+F5 强刷）。

4. 结束时回到该终端按 `Ctrl+C`。

端口 8000 被占用（报 `EADDRINUSE`）时：

```powershell
# PowerShell 换端口
$env:PORT=8001; npm start

# 或查出并结束占用进程
Get-NetTCPConnection -LocalPort 8000 -State Listen | Select-Object OwningProcess
Stop-Process -Id <PID>
```

## 操作

| 按键 | 作用 |
| --- | --- |
| W A S D / 方向键 | 八方向移动（坦克朝向即射击方向，可斜向开火） |
| J / 空格 | 开火（按住连射） |
| Esc | 暂停 / 继续 |

## 玩法

- 平衡型一击必杀；速度型/防御型有 2 点血量，按伤害累计结算。无装备时射击间隔 1 秒，子弹可反弹 4 次。
- **经典模式**：清光所有人机即胜利；**肉鸽模式**：人机每 15 秒一次性补满至「人数 - 1」，刷新位置随机且远离玩家，无尽生存并累计击杀。
- 地图为经典迷宫砖墙，尺寸随人数放大：1v1 = 2×2、4 人 = 4×4、8 人 = 6×6（基准地图的宽高倍数），镜头跟随并带小地图；装备位置在小地图上用彩色闪烁点标出，出屏时画面边缘有同色箭头指向。
- 每 15 秒在随机位置刷新一件装备，场上不限数量，30 秒未拾取则消失；人机同样会拾取并使用装备。

### 坦克类型

开局在菜单选择，人机固定为平衡型。

| 类型 | 血量 | 速度 | 伤害 | 特点 |
| --- | --- | --- | --- | --- |
| 平衡型 | 1 | 120 px/s | 1 | 当前默认手感，一击必杀 |
| 速度型 | 2 | 240 px/s | 0.5 | 双倍速度、半伤；打防御型需要 4 次命中 |
| 防御型 | 2 | 60 px/s | 1 | 半速、需要两次命中才死亡 |

伤害按命中次数结算：普通弹丸与霰弹的每一发各算一次命中；激光每次经过算一次（反弹回来算新命中）；穿透激光对每个目标只算一次。反甲反弹的正是「本次受到的伤害值」。

### 装备

| 装备 | 效果 |
| --- | --- |
| 激光 | 3 次；瞬时光线，最多反弹 4 次，第 5 次碰到墙停止 |
| 穿透激光 | 1 次；蓄力 1 秒，宽度等于车身，距离无限，贯穿并破坏墙体，不反弹 |
| 霰弹 | 5 次；一次 3 发并行弹丸，每发可反弹 6 次 |
| 快速射击 | 10 秒；射击间隔 0.3 秒，子弹反弹 4 次 |
| 无敌 | 10 秒；免疫一切攻击，但仍会被墙体和其他坦克阻挡 |
| 反甲 | 10 秒；免疫该次伤害并把攻击者淘汰（伤害返还给攻击者） |

## 结构

```
index.html        界面骨架（菜单 / HUD / 结算）
styles.css        像素风格样式
server.mjs        零依赖静态服务器
src/config.js     常量、装备表、人数与地图倍率
src/map.js        迷宫生成、碰撞查询、出生点与连通性
src/entities.js   坦克 / 子弹 / 装备实体
src/weapons.js    开火逻辑、激光反弹、穿透光束、装备生效
src/ai.js         人机寻路、瞄准与开火
src/render.js     Canvas 绘制与小地图
src/main.js       游戏循环、输入、状态机、HUD
tests/smoke.mjs   逻辑冒烟测试（迷宫连通、激光反弹、穿透、装备计时）
```

## 说明

- 八方向移动与斜向开火：转弯按轴分解，贴墙时会沿墙滑动；子弹与激光按墙面的法线方向反弹（斜射时反弹为镜面反射）。
- 霰弹采用「三发平行弹丸」而非扇形散射：本作的反弹按四方向法线计算，平行三发与碰撞模型一致。
- 人机同样会拾取装备并使用对应武器。
- 基础地图为 8×7 格，按人数放大后 1v1 为 16×14 格（512×448 像素）。
